# React Todo List App
A simple Todo List application built using React. This app allows users to add, edit, and delete tasks.

## Live Demo
[Click here to view the Todo List App](https://meghanayannam21.github.io/react-todo-list-app/)

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Simple and clean user interface

## Technologies Used
- React.js
- HTML
- CSS
- JavaScript

## How to Run the Project
Follow these steps to run the project on your computer.

### 1. Download the Project
- Open the GitHub repository.
- Click the **Code** button.
- Select **Download ZIP**.
- Extract the downloaded ZIP file.

### 2. Open the Project
- Open the extracted folder.
- Open the `react-todolist-app` folder in VS Code.
- Open the terminal.

### 3. Install Dependencies
Run the following command:

```bash
npm install
```

### 4. Start the Application
Run:

```bash
npm start
```

The application will open in your browser at:

```text
http://localhost:3000
```

**Note:** If you are using a newer Node.js version and encounter the `ERR_OSSL_EVP_UNSUPPORTED` error, try this in PowerShell before starting the app:

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
npm start
```
